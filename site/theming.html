Theming

Teal is the default accent and needs no class. Four more accent families apply with a single theme-* class on any ancestor, and a heritage dark scope is available as corpo-dark. Every color in the system resolves through --corpo-* tokens.

Accent themes

Dark scope

Dark Accent Operational

Apply corpo-dark on an ancestor. Surfaces, borders, text tiers, status colors, and the chart palette all carry dedicated dark-surface values — chart series in particular use separately validated muted steps rather than a brightness flip.

Key tokens

TokenPurpose
--corpo-bg / --corpo-bg-panelPage background / card and panel surfaces
--corpo-text … --corpo-text-dimFour text tiers, all WCAG AA on light surfaces
--corpo-accent / --corpo-accent-strong / --corpo-accent-subtleThe active theme's accent family
--corpo-green/red/amber/blue + -subtleStatus palette — reserved for status, never chart series
--corpo-chart-1 … --corpo-chart-5Categorical chart series, CVD-validated, fixed order
--corpo-border / -dim / -strongBorder weights
--corpo-radius / --corpo-radius-lg2px controls, 4px surfaces
--corpo-shadow-sm/md/lgQuiet elevation — no glow
--corpo-font-sans / --corpo-font-monoPublic Sans body, JetBrains Mono for labels and data
